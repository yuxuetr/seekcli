# 评估口径（Scoring Rubric）

> 让「完成度 60%」这类说法可复核、可跨次比较。每次评估都应声明用的是哪套坐标系。

## 1. 为什么需要固定口径

SeekCLI 曾以 harness-engineering 讲义图3 当验收清单，得出「12 项组件全部落地」。
换成 `deepseek-harness` 当坐标系后，同样的代码得分从「完整」变成「约 40%」。

**两次都没错，错的是把两个口径的数字直接比较。** 因此约定：

> 任何「完成度 X%」的表述，必须同时给出**坐标系**与**评估时间**。

## 2. 四个正交口径

| 口径 | 问的问题 | 适用场景 |
| --- | --- | --- |
| **A. 纠偏机制口径** | 单次调用内，harness 是否具备区别于裸 ReAct 的运行时机制？ | 判断「引擎好不好用」 |
| **B. 组件全景口径** | 对照一份成熟 harness 的组件清单，缺哪些框？ | 判断「还差什么」 |
| **C. 产品形态口径** | 除作者外，别人能不能装上、扩展、集成？ | 判断「是不是个项目」 |
| **D. 自进化地基口径** | 这个系统能不能自己长出新能力，并把对的留下？ | 判断「能不能自己长」 |

SeekCLI 在三个口径下的分数差异巨大（A ≈ 85%，B ≈ 45%，C ≈ 25%），
这个差异本身就是最有信息量的结论：**引擎强、面窄、产品化弱**。

### 2.1 D 口径为什么必须独立

B 口径问「对照一份成熟 harness 的组件清单缺哪些框」，**答不了「能不能自己长」**。
两者正交到可以完全背离：一个组件齐全但全部编译期焊死的 harness，
B 口径满分，D 口径接近零分。

D 口径按七个条件打分，前四条问**怎么产生变异**，后三条问**怎么保留正确的变异**：

| # | 条件 | 缺了会怎样 |
| --- | --- | --- |
| 1 | 自描述 | 自修改退化成穷举盲试 |
| 2 | 自修改 | 只能等人改代码 |
| 3 | 可逆 | 长会话累积孤儿注册，单向熵增 |
| 4 | 分档持久 | 实验性变异污染生产配置 |
| 5 | **可判定的评价信号** | 进化 = 随机游走 |
| 6 | 选择压力 + 闸门 | 能力面无限膨胀 |
| 7 | 否决记账 | 重提上一轮已否决的方案 |

**第 5 条是分水岭**：变异若无法被机器判定好坏，其余六条做得再好也只是「可编程」，
不是「可进化」。完整论证见 [2026-09-12 三评](2026-09-12-self-evolution-baseline.md#1-七条件模型本次方法学产出)。

## 3. 分层评分标准

每层按下列四档判定，不做小数点精度：

| 档位 | 含义 |
| --- | --- |
| ✅ 90%+ | 该层职责完整覆盖，且有扩展点 |
| 🟢 70-89% | 主路径完整，缺扩展点或边缘场景 |
| ⚠️ 40-69% | 有骨架，存在结构性缺口或边界不自洽 |
| ❌ <40% | 仅有最小实现或缺失 |

**关键约束：只有能指出具体证据（文件:行号 / 缺失的 grep 结果 / 无法完成的用户动作）的缺口才计分。**
「感觉不够完善」不计分。

## 4. 缺口分级

| 级别 | 判据 | 处理 |
| --- | --- | --- |
| **架构级** | 补它需要改变数据模型或控制流骨架，越晚越贵 | 优先排期，允许推倒重来 |
| **功能级** | 补它是新增模块，不动既有骨架 | 按收益排序 |
| **取舍级** | 明确写入 `security-model.md` / `design-principles.md` 的主动不做 | 不计入缺口，但需在评估中复述以免遗忘 |

## 4.1 缺口的三种状态

首版只有两种——**已排期**与**明确不排期**。推进完一轮路线图后发现，
这个模型少了一个状态：**「没做完，但也不是不做」**。落在这个缝里的项
只能悄悄留在层文档的表格里，路线图上看不见。

| 状态 | 含义 | 记在哪 |
| --- | --- | --- |
| 已排期 | 某个阶段拥有它 | `TODOs.md` 的阶段条目 |
| **已知仍开放** | 在阶段边界上有意留下，写了理由 | `TODOs.md` 的「🔵 已知仍开放」 |
| 明确不排期 | 判定为不做 | `TODOs.md` 的「⚪ P3」 |

`scripts/check-gap-coverage.py` 强制每个缺口恰好落在一个桶里，
并比对「层文档标为开放的缺口」与「路线图里的完成状态」——
两边不一致就失败。L7-1 / L7-4 曾在工作完成后仍被标为开放很久，就是因为没有东西比对两边。
